## What is blocking `stage` from advancing

**`Mod/About/ModIcon.png` does not exist, and this session will not create it.** AUDIT.md is
explicit: *"seule la propriétaire du mod génère un ModIcon. Un audit ou une session ne doit
jamais en générer, modifier, remplacer ni en demander la génération à un autre agent."* The user
asked this session to generate one; this rule is followed instead, and the request is declined
here rather than silently ignored.

A stray file was found at `Mod/About/ModIcon.png` when reconstruction began: 1254x1254 pixels
(far larger than the 128x128 a delivered icon needs), with no git history anywhere in this
repository's lineage and no reference to it in any document. Its origin is unknown — it may be a
source image dropped there for resizing, or an accidental leftover from something else. It has
been moved, untouched, to `Art/ModIcon-stray-1254.png`, out of the path Steam publishes, rather
than deleted, resized, or used as-is.

`Mod/About/Preview.png` **was** generated by this session: composed from the mod's own shipped
textures (`_tools/preview.js` + Chrome headless, the same approach used for the deleted 2026-09-06
build), 896x504, 62,579 bytes — well under the 1 MB limit. Preview generation is not reserved to
the owner the way ModIcon generation is; only the icon decision above blocks the stage.
